# Пробный GOP-драйвер для RTX 4060 Ti

Код рассчитан на PCI 10DE:2803 и пробует передать macOS уже существующее
изображение, которое настроил BIOS. Цель следующего испытания — выяснить,
сможет ли открыться графический установщик. Это не полноценный NVIDIA-драйвер:
ускорения, Metal, новых разрешений, сна и пробуждения здесь нет.

Исходники адаптированы из OpenNVDA, commit
2044adc11ceea642b2798b1943c292891562ae2b, с сохранением MIT-лицензии.
Поддержка этой карты и загрузка графики в macOS Tahoe не подтверждены.

## Что проверено

- Проверка C++-исходников LLVM 20.1.8 с MacKernelSDK, x86_64, macOS 11 target.
- Проверки 64-битных адресов, размера экрана, шага строки и границ BAR1.
- Независимая проверка кода и объявлений интерфейсов IOFramebuffer.

В исходном пакете готового драйвера пока нет. Код ядра не запускался, флешка и внутренние диски
не изменялись. Проверка компилятором не подтверждает запуск на этом компьютере.

## Подготовленная сборка

Скрипт build_mac.py требует настоящие инструменты Apple в macOS.
Windows LLVM ld64.lld 20.1.8 не реализует создание MH_KEXT_BUNDLE.
Дополнительно Windows заблокировала запись clang.exe в папку проекта;
защита не отключалась и заблокированная запись не обходилась.

В .github/workflows/build-kext.yml подготовлена ручная сборка на стандартном
сервере GitHub с macOS. Для публичного репозитория такие запуски бесплатны:
https://docs.github.com/en/actions/reference/runners/github-hosted-runners
Виртуальную машину на свой компьютер устанавливать не требуется.

Для запуска потребуется отдельный публичный репозиторий с файлами именно
этого исходного пакета в корне, включая папку .github. Затем Actions →
Build experimental GOP kext → Run workflow. При успешной сборке появится
артефакт NVGopFramebuffer2803-UNTESTED. Сборка также может завершиться ошибкой;
её журнал позволит исправить конкретный дефект.

В репозиторий отправляется только этот код, описание, лицензия и сведения о
его происхождении. Файлы компьютера, старые EFI, логи и компилятор туда
добавлять не нужно. Из этой папки пока ничего никуда не опубликовано.

Перед записью на флешку готовый бинарный файл и список его зависимостей
требуют проверки. Даже правильный формат файла не подтверждает совместимость
с ядром Tahoe или появление интерфейса установщика.
